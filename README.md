## 🧑‍🎤 Who Am I? <img src="https://media.giphy.com/media/WUlplcMpOCEmTGBtBW/giphy.gif" width="35">

I'm **VISHNU P**, an **AI Engineer** with hands-on experience designing and developing production-oriented Generative AI systems, Retrieval-Augmented Generation (RAG) applications, and robust backend architectures. 

- 🤖 **GenAI & RAG:** Expert in building production RAG pipelines using **LangChain, LangGraph, ChromaDB, and FAISS**, paired with hybrid search (TF-IDF, BM25, Semantic Similarity).
- ⚡ **Backend Engineering:** Building high-performance APIs and AI microservices using **FastAPI** and **Django/DRF**.
- 📊 **LLM Observability:** Experienced with **Langfuse, RAGAS, and LangSmith** for prompt monitoring, tracing, and feedback-based optimization.
- 🗄️ **Data & Storage:** Proficient with **MongoDB, PostgreSQL, SQLite, and Amazon S3** for state persistence and vector data management.
